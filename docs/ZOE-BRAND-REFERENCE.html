Non-Negotiable Principles

Use whitespace generously

Let elements breathe. Content is curated, not crowded. Minimum 48px between sections.

No gradients

Colors should be solid and architectural. Depth is achieved via tonal layering, never blurs.

Restrained use of Jade

Jade is for action and focus. Do not flood large surfaces with green; use Oat as the canvas.

Apple-like softness

Use generous 24px-32px radii. Everything should feel soft, touchable, and modern.

Calm balance

Favor balanced composition over rigid grids or editorial chaos.

Atmospheric shadows

If a shadow is used, it must be felt, not seen. Keep opacity around 4% max.

Literal iconography

Use 2px stroke icons that match the visual weight of the type.

Solid paper aesthetic

The UI should feel like stacked sheets of premium cardstock, not digital glass.
